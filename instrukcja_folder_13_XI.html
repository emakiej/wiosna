Mój folder na dzisiejszą lekcję

W swoim folderze utwórz nowy folder o nazwie 13.XI.

Dokumenty → Twój folder → 13.XI

Instrukcja krok po kroku

1

Otwórz Eksplorator plików.

Kliknij żółtą ikonę folderu na pasku zadań.

Możesz też nacisnąć razem Windows + E.

2

Otwórz Dokumenty i znajdź swój folder.

Otwórz go dwukrotnym kliknięciem, np. AnnaKo.

Pamiętasz? Nazwa to Twoje imię + pierwsze dwie litery nazwiska.

3

Utwórz folder wewnątrz swojego folderu.

Kliknij prawym przyciskiem myszy w puste miejsce — nie na plik ani folder.

Wybierz Nowy → Folder.

4

Wpisz nazwę i zatwierdź.

13.XI

Naciśnij Enter. Wpisz wielkie X oraz I.

Kropka jest tylko po 13. Nie dodawaj kropki na końcu nazwy.

5

Sprawdź miejsce utworzenia folderu.

Folder 13.XI ma być w Twoim folderze, a nie obok niego.

Dokumenty
AnnaKo ← tutaj będzie nazwa Twojego folderu
13.XI

C:\Users\WiosnaUczen\Dokumenty\<FOLDER_UCZNIA>\13.XI

Jeśli folder 13.XI już istnieje w Twoim folderze, po prostu go otwórz. Nie twórz drugiego.

Gotowe! Tutaj będziesz zapisywać dzisiejsze prace.
