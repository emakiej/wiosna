📝 Word — moja przygoda z tekstem

Utworzysz dokument, skopiujesz historyjkę i nauczysz się przenosić zdania.

Poćwiczysz też cofanie pomyłek i zapisywanie pracy.

Pracę zapisz w Twoim folderze: imię + pierwsze dwie litery nazwiska.

Przykład: Anna Kowalska → AnnaKo
Miejsce zapisu: Dokumenty → Twój folder

⌨️ Jak naciskać skróty?

Przytrzymaj Ctrl, naciśnij drugą literę, a potem puść oba klawisze.

Ctrl + C
Nie naciskaj znaku „+”! Pokazuje on tylko, które klawisze trzeba połączyć.

1. Otwórz Worda i zapisz dokument

1Otwórz Worda

  1. Naciśnij klawisz z logo Windows.
  2. Wpisz „Word”.
  3. Kliknij aplikację „Word”.
  4. Wybierz „Pusty dokument”. Jeśli trzeba, najpierw kliknij „Nowy”.
Nie widzisz Worda? Poproś nauczyciela o pomoc.

2Wpisz tytuł

Kliknij białą kartkę i napisz:

Moja przygoda z tekstem

Naciśnij Enter, aby przejść do nowego akapitu.

3Zapisz dokument w swoim folderze

  1. Kliknij „Plik” → „Zapisz jako”.
  2. Jeśli pojawi się wybór miejsca, wybierz „Ten komputer” i „Przeglądaj”.
  3. Otwórz „Dokumenty”.
  4. Otwórz swój folder, klikając go dwa razy.
  5. W polu „Nazwa pliku” wpisz „MojeCwiczenia”.
  6. Sprawdź, czy typ pliku to „Dokument programu Word (*.docx)”.
  7. Kliknij „Zapisz”.
Dokumenty → Twój folder → MojeCwiczenia.docx
Użyj swojego folderu, a nie przykładowego „AnnaKo”.

2. Skopiuj historyjkę do Worda

4Zaznacz tekst: Ctrl + A

  1. Wróć do tej strony w przeglądarce.
  2. Kliknij wewnątrz ramki z historyjką.
  3. Naciśnij Ctrl + A.

Cała historyjka w ramce powinna się zaznaczyć.

Najpierw kliknij w ramkę! Inaczej możesz zaznaczyć całą stronę zamiast samej historyjki.

5Kopiuj: Ctrl + C

Gdy historyjka jest zaznaczona, naciśnij Ctrl + C.

Komputer zapamięta tekst w schowku. Historyjka zostanie na stronie.

Schowek jest jak niewidzialna kieszonka na skopiowany tekst.

6Wklej: Ctrl + V

  1. Kliknij ikonę Worda na pasku zadań.
  2. Kliknij pusty akapit pod tytułem.
  3. Naciśnij Ctrl + V.
Historyjka powinna pojawić się w Twoim dokumencie!

3. Kopiuj i przenoś zdania

7Zrób kopię zdania

  1. Zaznacz myszką zdanie „Kot znalazł mapę.” razem z kropką.
  2. Naciśnij Ctrl + C.
  3. Kliknij za kropką w ostatnim zdaniu historyjki.
  4. Naciśnij Enter.
  5. Naciśnij Ctrl + V.
Sprawdź: zdanie „Kot znalazł mapę.” jest teraz dwa razy. Kopiowanie nie zabrało go z początku.

8Przenieś zdanie: Ctrl + X

  1. Zaznacz zdanie „W ogrodzie czekał mały robot.” razem z kropką.
  2. Naciśnij Ctrl + X. Zdanie zniknie z tego miejsca.
  3. Kliknij na końcu ostatniego zdania dokumentu.
  4. Naciśnij Enter.
  5. Naciśnij Ctrl + V.
Zdanie o robocie jest teraz na końcu. Wycięcie i wklejenie przeniosło je w nowe miejsce. Pusty wiersz w środku może na razie zostać.
Po wycięciu od razu wklej zdanie. Nie kopiuj w międzyczasie innego tekstu.

9Zaznacz cały dokument: Ctrl + A

  1. Kliknij wewnątrz tekstu w Wordzie.
  2. Naciśnij Ctrl + A.
  3. Zobacz: zaznaczył się cały tekst, także tytuł.
  4. Kliknij raz na końcu tekstu, aby usunąć zaznaczenie.
Gdy tekst jest zaznaczony, wpisanie nowych liter zastąpi zaznaczoną treść. W tym ćwiczeniu tylko oglądamy zaznaczenie.

4. Cofnij pomyłkę i zapisz zmiany

10Cofnij pomyłkę: Ctrl + Z

Teraz celowo usuniemy jedno słowo, a potem je przywrócimy.

  1. Znajdź w dokumencie słowo „robot”.
  2. Kliknij dwa razy w to słowo, aby je zaznaczyć.
  3. Naciśnij Backspace. Słowo zniknie.
  4. Naciśnij Ctrl + Z.
  5. Sprawdź: czy słowo „robot” wróciło?
Udało się! Cofnięcie przywróciło usunięte słowo. Ctrl + Z pomaga naprawiać pomyłki.
Naciskaj skrót po jednym razie i sprawdzaj efekt. Kolejne naciśnięcia mogą cofnąć także wcześniejsze czynności.

11Zapisz zmiany: Ctrl + S

Twój dokument ma już nazwę i swoje miejsce. Teraz zapisz to, co udało Ci się zmienić.

  1. Kliknij na końcu tekstu.
  2. Naciśnij Enter.
  3. Napisz: „Umiem zapisać swoją pracę!”.
  4. Naciśnij Ctrl + S.
Zmiany zapisujesz w tym samym pliku. Nie musisz za każdym razem wpisywać jego nazwy.
Jeśli pojawi się okno wyboru miejsca zapisu, wybierz „Dokumenty” → swój folder. Wpisz nazwę „MojeCwiczenia” i kliknij „Zapisz”. Jeśli komputer pyta o zastąpienie pliku, poproś nauczyciela o pomoc.

12Sprawdź, czy praca się zapisała

  1. Po zapisaniu zamknij dokument.
  2. Jeśli Word zapyta o zapisanie zmian, wybierz „Zapisz”.
  3. Otwórz Eksplorator plików.
  4. Wejdź do „Dokumenty”, a potem do swojego folderu.
  5. Kliknij dwa razy plik „MojeCwiczenia”.
  6. Sprawdź, czy na końcu jest zdanie: „Umiem zapisać swoją pracę!”.
Zdanie jest na miejscu? Brawo! Twoja praca została zapisana.

Ctrl + C

Kopiuj zaznaczony tekst. Oryginał zostaje.

Ctrl + V

Wklej tekst ze schowka w miejscu kursora.

Ctrl + X

Wytnij zaznaczony tekst, aby go przenieść.

Ctrl + Z

Cofnij ostatnią czynność.

Ctrl + S

Zapisz swoją pracę.
